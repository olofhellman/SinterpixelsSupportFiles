# SinterpixelsSupportFiles

This repo is for freely available support files for <a href="https://tomographic.com/Sinterpixels">SinterPixels</a>, a scriptable macOS application for drawing shapes and manipulating pixels.

Most of this repo is this documentation on how to use <a href="https://tomographic.com/Sinterpixels">SinterPixels</a>. There are also some sample data files in the data directory, and some sample scripts in the scripts directory. See the [Table of Contents](docs/TableOfContents.md) for a more organized presentation of the repo contents.

Browse the [Examples Catalog](docs/AllExamples.md) for an idea of what Sinterpixels can do:

If you are new to the app, it is strongly recommended to start by going in order through the first three links, "Opening a File", "Using the Scripting Interface", and "Shapes Part 1"

- [Opening a File](docs/OpeningAFile.md)
- [Using the Scripting Interface](docs/TheScriptingInterface.md)
- [Shapes Part 1](docs/SinterpixelsShapes.md)
